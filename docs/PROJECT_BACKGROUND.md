# Academic context and attribution

The historical 2017–2018 undergraduate **Car Accident Alert System** was a two-person project from the Electronics and Telecommunication program at Government College of Engineering, Karad.

The report describes an Arduino/ATmega328P, ADXL335 analog accelerometer, GPS receiver, GSM modem and LCD. The team also reported Proteus simulation and a hardware demonstration that generated location-bearing messages.

This repository is an **independent, newly written educational reconstruction**. It does not distribute the original team's code, student roll numbers, third-party contact details, photographs or historical PDF.

No real-world collision recognition performance or production reliability has been demonstrated. Credit the original university work as a team effort when presenting the project.
